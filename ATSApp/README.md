# Career Path Builder

A comprehensive web application built with HTML, CSS, and JavaScript to help users build their career paths through job search, mock exams, and skill assessment.

## Features

### 1. **Authentication System**
- User Login with email and password
- User Registration/Sign Up
- Social Login Integration (LinkedIn, Facebook, Twitter, Instagram)
- Session management with localStorage

### 2. **User Profile Management**
- Comprehensive profile creation
- Personal information (Name, Email, Phone, DOB, Location)
- Education details (Qualification, Specialization, University, CGPA)
- Experience tracking (Years, Job Title, Company, Skills)
- Career preferences and objectives
- Social media links integration
- Resume upload
- Passport-size photo upload

### 3. **Job Search & Discovery**
- Browse all available jobs
- Advanced filtering:
  - By location
  - By job role
  - By experience level
  - By salary range
- Job recommendations based on education
- Detailed job view with requirements and skills
- Apply for jobs directly from the platform

### 4. **Mock Exams**
- Fresher-friendly basic tests
- Multiple exam categories:
  - Technical exams
  - Aptitude tests
  - Interview preparation
- Filter exams by difficulty and category
- Start exams with timer
- Job preference-based exam recommendations

### 5. **Score Card & Results**
- View all exam results
- Detailed score analysis
- Performance metrics
- Download scorecards
- Performance history tracking
- Score sorting and filtering

### 6. **Application Form**
- Dynamic forms based on education
- Pre-filled job information
- Educational background verification
- Experience and skills input
- Resume and photo upload
- Cover letter section
- Terms and conditions acceptance

### 7. **Dashboard**
- Profile completion status
- Available job listings
- Mock exam count
- Application tracking
- Recent activity log
- Quick navigation to all modules
