# Family Tree Customization Guide

## Overview
The family tree now includes extensive customization options for each person card, allowing you to personalize shapes, colors, and add links.

## Features Added

### 1. **Shape Options**
Choose from 4 different shape styles for person cards:
- **Rectangle** - Sharp corners, minimal design
- **Rounded** - Soft rounded corners (default)
- **Circle** - Circular person cards
- **Hexagon** - Unique hexagonal shape

### 2. **Color Customization**
Customize three color aspects for each person card:
- **Background Color** - Change the card's background color
- **Border Color** - Modify the border color
- **Text Color** - Adjust the text color for better readability

### 3. **Link Attachment**
- Add external links to person cards
- Links can point to:
  - Personal websites
  - Social media profiles
  - Photo albums
  - Document repositories
  - Memorial pages
  - Any other relevant URL
- Linked cards display a 🔗 indicator in the top-right corner
- Click the card (outside action buttons) to open the link in a new tab

### 4. **Style Reset**
- Reset any person card back to default styling with one click
- Removes all custom colors, shapes, and formatting

## How to Use

### Accessing the Customization Menu

1. **Hover over any person card** to reveal action buttons
2. **Click the "🎨 Style" button** to open the customization menu
3. The menu will appear on the right side of the screen

### Changing the Shape

1. Open the customization menu for the person
2. In the "Shape" section, click on any of the 4 shape preview buttons
3. The person card will immediately update with the new shape
4. The selected shape will be highlighted in the menu

### Customizing Colors

1. **Background Color:**
   - Click the background color picker
   - Select your desired color
   - Click "Apply" to update the card

2. **Border Color:**
   - Click the border color picker
   - Select your desired color
   - Click "Apply" to update the card

3. **Text Color:**
   - Click the text color picker
   - Select your desired color
   - Click "Apply" to update the card

### Adding a Link

1. Open the customization menu
2. In the "Add Link" section, enter a full URL (e.g., `https://example.com`)
3. Click "Add Link"
4. A 🔗 indicator will appear on the card
5. Click anywhere on the card (except action buttons) to open the link

### Removing a Link

1. Open the customization menu for a card with a link
2. In the link section, you'll see the current link displayed
3. Click the "Remove Link" button
4. The link and 🔗 indicator will be removed

### Resetting to Default Style

1. Open the customization menu
2. Scroll to the bottom
3. Click the "Reset to Default" button
4. All custom styling will be removed, returning to the original appearance

## Tips and Best Practices

### Color Combinations
- Ensure good contrast between background and text colors for readability
- Use darker text on light backgrounds
- Use lighter text on dark backgrounds

### Shape Selection
- **Circle** works best for portrait photos
- **Hexagon** provides a unique, modern look
- **Rounded** is the most versatile default option
- **Rectangle** gives a formal, structured appearance

### Link Usage Ideas
- Link to online genealogy profiles
- Connect to photo galleries
- Link to biographical documents
- Add memorial or tribute pages
- Connect to social media profiles
- Link to video interviews or documentaries

### Organization
- Use consistent colors for different family branches
- Apply similar shapes to members of the same generation
- Use color coding to indicate specific attributes (e.g., locations, professions)

## Technical Notes

### Browser Compatibility
- Works in all modern browsers (Chrome, Firefox, Safari, Edge)
- Color picker requires modern browser support
- Links open in new tabs for better user experience

### Export Compatibility
- Custom styles are preserved when exporting as PNG
- Custom styles are preserved when exporting as PDF
- Links are not interactive in exported images but remain visible through the 🔗 indicator

### Persistence
- Customizations are applied in real-time
- Styles remain applied until reset
- Currently, customizations are not saved between page reloads (future enhancement)

## Troubleshooting

### Customization Menu Not Opening
- Ensure JavaScript is enabled in your browser
- Try refreshing the page
- Check that you're clicking the "🎨 Style" button

### Colors Not Applying
- Make sure to click the "Apply" button after selecting a color
- If colors don't appear correct, try resetting and reapplying

### Link Not Working
- Ensure the URL includes `http://` or `https://`
- Check that the URL is valid and accessible
- Links only work when clicking outside the action buttons area

### Shape Not Changing
- Some shapes require more padding and may adjust card size
- Try refreshing the page if shapes don't apply correctly
- Reset to default and try again
