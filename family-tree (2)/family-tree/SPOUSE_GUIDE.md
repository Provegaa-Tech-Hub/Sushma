# Spouse Connection Guide

## How Spouse Connections Work

### Visual Structure
When you add a spouse to a person:

1. **Horizontal Marriage Line**: A pink line (3px) connects the two people
2. **Heart Symbol (💕)**: Appears between the couple
3. **Shared Children**: Children appear below the PRIMARY parent (first person)
4. **No Duplicate Lines**: Spouse nodes don't have vertical tree connectors

### Key Rules
- Each person can have only ONE spouse
- Spouse button hidden once spouse is added
- Removing a person unlinks their spouse relationship
- Children always connect from the non-spouse parent
